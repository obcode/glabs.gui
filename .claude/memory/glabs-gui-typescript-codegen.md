glabs.gui was migrated from JavaScript+JSDoc to **real TypeScript** with **GraphQL Codegen** (PR #28, `refactor: migrate to TypeScript with codegen-typed GraphQL`, branch feat/typescript-codegen, CI green). Decided deliberately after the GUI had started out as JavaScript: the chosen scope was TypeScript **plus** codegen from the schema, not a bare `.js` → `.ts` rename.

How it works now (for any future GUI GraphQL work):
- Write operations with `graphql(\`...\`)` imported from **`$lib/gql`** (generated by `@graphql-codegen/client-preset`) — NOT `import { gql } from 'graphql-request'` anymore. Returns a `TypedDocumentNode<Result, Vars>`.
- `backendRequest(doc, vars)` ($lib/server/backend) and `gqlProxy(doc, vars)` ($lib/server/gqlProxy) forward those types; `vars` is optional for no-variable ops, required otherwise (conditional-tuple rest param).
- **Operation names must be globally unique** (client-preset requirement). E.g. the layout's `query Me` and hooks' `query AuthCheck` are two names for the same `me` query.
- `schema.graphql` at repo root is a **checked-in copy** of the backend schema, pulled via `pnpm schema:pull` from `../glabs/web/graph/*.graphqls`. On backend schema changes: `pnpm schema:pull && pnpm codegen`, commit both. Codegen/typecheck run in CI without a backend.
- Generated output in **`src/lib/gql/`** is committed but prettier/eslint-ignored. `dev`/`check`/`build` all run `graphql-codegen` first (so does the Docker build).
- codegen.ts config: `enumsAsTypes: true` (enums are string-literal unions so `field.kind === 'BOOL'` compares directly), `scalars: { Time: 'string' }`, `fragmentMasking: false`.
- Deps added: @graphql-codegen/cli, @graphql-codegen/client-preset, @graphql-typed-document-node/core, svelte2tsx. The last two were needed explicitly (typed-document-node import + plucking gql from .svelte files) under pnpm's strict layout.
- The dynamic schema-driven assignment form legitimately uses `Record<string, any>` for form/row values (bind:value/bind:checked over arbitrary keys); everything else is strictly typed.

**TypeScript stays on 5.x**: TS 7 (Go-based tsc) crashes the current svelte-check — this is why dependabot #8 was closed. Bump to TS 7 only once svelte-check supports it. See [[glabs-gui-ci-dependabot]].
